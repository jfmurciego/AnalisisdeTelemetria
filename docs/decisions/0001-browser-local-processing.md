# ADR-0001: procesamiento local en navegador

- Estado: aceptada
- Fecha: 2026-09-11

## Decisión

Procesar la telemetría real en el navegador y no persistirla por defecto. Git contiene código, documentación y fixtures sintéticos.

## Consecuencias

Reduce exposición de ubicaciones y hábitos. Limita inicialmente el tamaño procesable y obliga a diseñar importación por streaming para archivos grandes.
